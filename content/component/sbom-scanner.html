Why SBOM Scanner?

SBOM-centric by design

Pull and unpack an image once. After that, every rescan reads the SBOM — fast, cheap, and light on bandwidth.

Less noise, real signal

Suppress known non-exploitable findings with VEX. KEV and EPSS prioritization are on the way.

Images, workloads, and nodes

Scan whole registries, only what is running in the cluster, or the host OS underneath.

Kubernetes-native

Registries, scans and reports are Kubernetes resources. Manage them with kubectl and GitOps.

Two ways to scan

Point it at your registries, or let it follow what your cluster is running.

Scan your registries

Control exactly which images get scanned.

  • Discover the whole registry, or list specific repositories
  • Filter tags with CEL: semver ranges, suffixes, regex
  • Choose which platforms and architectures to scan
  • Works with registries that have no catalog API
registry.yaml
apiVersion: sbomscanner.kubewarden.io/v1alpha1
kind: Registry
metadata:
  name: my-registry
spec:
  uri: ghcr.io
  scanInterval: 1h
  platforms:
    - os: linux
      arch: amd64
  repositories:
    - name: my-org/my-app
      matchOperator: Or
      matchConditions:
        - name: production tags
          expression: "tag.endsWith('-prod')"

Follow your workloads

Scan only what is actually running.

  • Discovers the images your Deployments, Jobs and Pods use
  • Scans only the tags in use, not the whole registry
  • One report per workload: what to fix in this Deployment
  • New workloads are picked up automatically
kubectl
# Reports are grouped by workload
kubectl get workloadscanreport -n my-namespace

# Which vulnerabilities affect this Deployment?
kubectl describe workloadscanreport my-app -n my-namespace

Ready to try it?

Install SBOM Scanner with Helm and start scanning your first registry.

# Requires cert-manager and CloudNativePG - see the quickstart
helm repo add kubewarden https://charts.kubewarden.io

helm install sbomscanner kubewarden/sbomscanner \
  --namespace sbomscanner --create-namespace \
  --set controller.replicas=1 --set storage.replicas=1 \
  --set storage.postgres.cnpg.instances=1 --set worker.replicas=1 \
  --wait
