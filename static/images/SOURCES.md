# Theme artwork sources

These SVG files are local copies of upstream artwork, without color changes or filters.

## Rancher by SUSE

- File: `rancher-suse-logo-horizontal-color.svg`
- Source: https://www.rancher.com/assets/img/logos/rancher-suse-logo-horizontal-color.svg
- Official color horizontal logo for light backgrounds.
- File: `rancher-suse-logo-horizontal-white.svg`
- Source: https://www.rancher.com/assets/img/brand-guidelines/assets/logos/svg/white/rancher-suse-logo-horizontal-white.svg
- Official white horizontal logo supplied through the Rancher brand guidelines.
- Used only on dark backgrounds. Both variants have the same `255.12 × 90.74` viewBox and use identical CSS sizing.

## Cloud Native Computing Foundation

- File: `cncf-color-whitetext.svg`
- Source: https://github.com/cncf/artwork/blob/main/other/cncf/horizontal/color-whitetext/cncf-color-whitetext.svg
- Official color mark with white text from the CNCF artwork repository.
- Used only on dark backgrounds; the existing color logo remains in light mode.

## Tux

- File: `tux.svg`
- Source: https://github.com/garrett/Tux/blob/master/tux.svg
- Original Tux illustration by Larry Ewing, created with the GIMP.
- Vector illustration by Garrett LeSage, created with Inkscape.
- Refinement and cleanup by IFo Hancroft.
- License: CC0 / public domain, as stated in the [upstream README](https://github.com/garrett/Tux/blob/master/README.md).
- The same artwork appears in both themes.
